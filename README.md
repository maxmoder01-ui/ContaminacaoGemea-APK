# Personagens 3D

- `torajo_base.glb`: arquivo 3D fornecido pelo usuário; importado no projeto e usado como modelo do jogador na primeira versão integrada.
- `torajo_texture_reference.jpeg` e `torajo_detail_reference.png`: texturas originais incluídas para referência.
- A Voluntária atual ainda usa uma malha procedural provisória no jogo.
- Morajo, Pessy, Jay, Linn e Zulmi ainda precisam de modelos individuais e referências visuais confirmadas. Não foram falsamente substituídos por cópias do Torajo.

O GLB pode conter rig e/ou animações originais; a presença de animações utilizáveis precisa ser verificada no editor Godot. O movimento do jogador atualmente anima a orientação do modelo, mas não promete animação esquelética de caminhada.
